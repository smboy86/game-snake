# 게임 엔진

이 프로젝트는 Phaser JS 게임 엔진을 사용합니다.

게임을 구성하는 주요 요소를 파악하려면 아래 Phaser 공식 시작 문서를 참고합니다.

https://docs.phaser.io/phaser/getting-started/making-your-first-phaser-game

애니메이션, 액션, 입력, 물리, 씬 구성 등 더 자세한 정보가 필요하면 Phaser 공식 문서를 기준으로 확인합니다.

https://docs.phaser.io/

Phaser에서 타일맵과 타일셋을 불러올 때는 `load.image('tiles' ...)`와 `load.tilemapTiledJSON('map', ...)` 방식을 사용합니다.
